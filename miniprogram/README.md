# 六宫掌图 · 微信小程序

这是从离线单页 HTML 版本移植的原生微信小程序项目，用于自己和朋友使用；当前包含小六壬与梅花易数两部分。

## 先说明：Apple ID 不能当小程序 AppID

- Apple ID 是苹果账号，和微信小程序无关。
- 微信小程序需要的是**微信小程序 AppID**，在微信公众平台注册小程序后获得。
- 没有 AppID 也可以先用项目里的 `touristappid` 在微信开发者工具里本地预览。
- 要让朋友在手机上扫码使用，需要一个真实的小程序 AppID，并上传体验版。
- 不要把 **AppSecret** 发给任何人；本项目不需要 AppSecret。

## 安装微信开发者工具

到微信官方文档下载安装：

<https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html>

安装后用微信扫码登录。

## 导入项目

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本文件夹：`miniprogram/`。
4. AppID：
   - 有正式 AppID：填自己的小程序 AppID；
   - 没有：选择“测试号”或使用 `touristappid`。
5. 点击导入，等待编译。

开源仓库中的 `project.config.json` 使用 `touristappid`，导入时请填写自己的小程序 AppID，或导入后替换该字段。

## 只给朋友用的体验版流程

1. 在微信公众平台注册一个小程序账号，拿到 AppID。
2. 在微信开发者工具中导入项目并填 AppID。
3. 点击“上传”，填写版本号，例如 `1.0.0`。
4. 登录微信公众平台 → 管理 → 版本管理。
5. 把刚上传的版本设为“体验版”。
6. 在“成员管理”里把朋友加为“体验成员”。
7. 把体验版二维码发给朋友，朋友扫码使用。

体验版**不需要提交审核、不需要发布**，但：
- 需要真实 AppID；
- 朋友必须被加为体验成员；
- 小程序名称/主体注册仍可能受微信规则限制；
- 小程序启动依赖微信环境，不保证像本地 HTML 一样完全离线。

- 农历闰月、大小月、三十日、子时边界校验。
- 六宫掌图：上排 留连 · 速喜 · 赤口；下排 大安 · 空亡 · 小吉。
- 六神、五星、六亲、全部藏干、单主支、后天八卦符号。
- 日起大安，按农历日顺数；日/时落宫标记（终点宫），五星从日落宫起木顺排。

- 掌图支持双指缩放、双击放大、单指拖动，右上角可“复位”。
- “排盘规则与口径”默认折叠，点击展开。
- 梅花易数：时分起卦，主卦、互卦、变卦三列并排，动爻高亮，卦线按上下卦五行配色。
- 每卦另标八宫归属（如泽火革属坎宫），并显示上/下卦的宫位、方位、五行。
- 梅花易数按五行配色：木青、火赤、土黄、金白、水黑。
- “所问之事”可自由填写，并随排盘结果一起复制。
- 时间旬空：显示年、月、日、时四柱及各自旬空（如丙午年 寅卯空）。
- 复制结果、手机适配、免责声明。
- 无外部 CDN、无网络请求、无需后端。

## 梅花易数时分起卦规则

- 只取起卦时间的**小时和分钟**，忽略年月日。
- 上卦：小时数除以 8 取余；余 0 作 8。
- 下卦：分钟数除以 8 取余；余 0 作 8。
- 动爻：小时数加分钟数，除以 6 取余；余 0 作 6。
- 先天八卦数：乾 1、兑 2、离 3、震 4、巽 5、坎 6、艮 7、坤 8。
- 例：10:27 → 上卦 10÷8 余 2 兑，下卦 27÷8 余 3 离，动爻 37÷6 余 1 初爻；主卦泽火革，互卦天风姤，变卦泽山咸。
- 互卦：主卦二、三、四爻为下卦，三、四、五爻为上卦。
- 变卦：主卦动爻阴阳变化后所得。
- 宫位：显示八宫归属与后天八卦宫位（乾西北、兑西、离南、震东、巽东南、坎北、艮东北、坤西南），并按五行配色。
- 时间旬空：按四柱干支计算六甲旬空；年柱以立春为界，月柱按节气，日柱按儒略日，时柱按五鼠遁。
